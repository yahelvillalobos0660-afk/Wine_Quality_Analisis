# 🍷 Wine Quality Prediction Project

Proyecto de análisis exploratorio y clasificación del dataset de Calidad de Vino Blanco usando Python y Scikit-Learn.

## 📁 Estructura del Proyecto
- `eda.py`: Limpieza de datos, matriz de correlación y análisis de multicolinealidad (VIF).
- `train.py`: Construcción de Pipelines, estandarización y optimización del modelo SVM.
- `predict.py`: Script de inferencia para clasificar nuevas muestras.
- `data/`: Contiene el conjunto de datos `winequality-white.csv`.
